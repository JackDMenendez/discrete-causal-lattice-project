## Summary
win-cross-dev-env **v0.3.1** is released to origin `main` and rolled to PROD
(`c:\prod\wcde`) on 2026-08-04. It closes out the Lean/Mathlib editor work and a
python-activation cleanup that were pending on the DEV tree after the isolation
feature (already shipped in v0.2.0/v0.3.0). This is the release the 2026-07-29
soak-confirmed handoff authorized — that handoff's isolation-specific asks were
already satisfied by prior releases (see its consumed note).

  launcher + `env/lean-env.cmd` elan/PATH + `env/mathlib-env.cmd`); ghcup added to

  uses the requires path, setup-vscode reads `DEV_SHELL_ACTIVE_VENV_PATH`.
- `3bf5bd7` — lean/vscode env wiring: `pwsh` into the vscode env chain +
  vscode-lean requires; lean-env pulls `mathlib`; `pwsh --version` diagnostic.

## Verification

  `WCDE_INCLUDE_PYTHON_VENV=1` + `DEV_SHELL_ACTIVE_VENV_PATH=C:\Users\jackd\.venv-win`;
  `setup-vscode.cmd` writes `python.defaultInterpreterPath` =
  `C:/Users/jackd/.venv-win/Scripts/python.exe` for a python launcher and omits it
